Work Package 2: Development of the Breath-Hold Detection Pipeline

Work Package 2 details the complete development of the temporal deep learning pipeline, which is the core of the breath-hold detection system. This phase translated the preprocessed data from Work Package 1 into a functional and robust model, encompassing the entire workflow from data ingestion to the final output of breath-hold segments.

The development was organized within a highly structured project directory to ensure modularity and complete reproducibility, which is critical for academic validation. The source code was primarily located in the `src` directory, which contained the definitions for the data handling and model architecture. Specifically, the `src/datasets/window_dataset.py` file defines the `WindowVideoDataset` class, which serves as the bridge between the data manifests and the model, while `src/models/mobilenet_temporal.py` contains the implementation of the `MobileNetV3Temporal` neural network. The high-level scripts for orchestrating the training and inference are located in `tools/core/`, with `train_final_v4.py` being the script for training the final model and `predict_video.py` for performing inference. All experiments, including model checkpoints and metadata, were saved to the `runs` directory, with the final model artifacts stored in `runs/final_model_v4_rgb_bce/`.

The process begins with the data pipeline, implemented in the `WindowVideoDataset` class, which consumes the CSV manifest files generated in Work Package 1, such as `manifest_final_train_v3.csv`. For each entry in the manifest, the corresponding 15-frame video clip is extracted using OpenCV. These frames, treated as raw RGB data, are then transformed into 224x224 PyTorch tensors and normalized using ImageNet statistics to leverage the pretrained backbone of the model. The binary ground truth label from the manifest—0 for "breathing" and 1 for "breath-hold"—is also loaded, preparing the data for the model in batches.

The neural network architecture, named `MobileNetV3Temporal`, is a temporal CNN that uses a pretrained MobileNetV3-Small as its feature extractor. Each frame of a video clip is passed through this backbone to extract spatial features. These features are then aggregated across the 15 frames using a temporal max pooling operation, which condenses the information into a single feature vector that represents the entire window. This vector is then passed to a classifier to produce a single logit, predicting the presence of a breath-hold.

The final model was trained using the `tools/core/train_final_v4.py` script, which employs a binary cross-entropy loss function with a positive class weight to counteract class imbalance. The model was trained for 15 epochs using the AdamW optimizer. After each epoch, the model's performance was evaluated on a validation set, and the model checkpoint that achieved the highest F1 score was saved as `final_best.pt`. All training hyperparameters and results were meticulously logged in `runs/final_model_v4_rgb_bce/final_meta.json` to ensure full reproducibility.

The inference process, orchestrated by `tools/core/predict_video.py`, loads the trained `final_best.pt` model and generates a continuous probability score for each window in a given video. This sequence of probabilities represents the model's confidence that a breath-hold is occurring over time.

A final probability threshold of 0.90 is applied to these scores to produce binary predictions. This threshold was chosen to optimize for high precision in the final segment-level output. To further enhance the reliability of the detections, a temporal post-processing step is applied, where any predicted breath-hold segment lasting less than 2.0 seconds is filtered out. The final output is a set of meaningful breath-hold segments, saved in `segments.csv`, which provides the start and end times of each detected event.
